# GESTOR 002

Sistema de manejo de cajas de ahorro

## Descripción del Proyecto

Gestor 002 es un sistema de manejo de cajas de ahorro que permite a los usuarios gestionar sus ahorros de manera eficiente y segura.

## Arquitectura del Sistema

El sistema está compuesto por las siguientes partes:

### Front End

- **Tecnologías:** React, Redux, CSS3, JavaScript
- **Descripción:** La interfaz de usuario que permite a los usuarios interactuar con el sistema.

### Back End

- **Tecnologías:** Java (Spring Boot).
- **Descripción:** El servidor que maneja la lógica de negocio y las operaciones del sistema.

### Esquema de Base de Datos

- **Base de Datos:** PostgreSQL
- **Descripción:** El esquema de la base de datos incluye tablas para usuarios, transacciones, y registros de ahorro.

## Configuraciones

### Desarrollo

- **Entorno:** Local
- **Configuraciones:** Variables de entorno, configuración de base de datos local, etc.

### Producción

- **Entorno:** Servidor en la nube
- **Configuraciones:** Variables de entorno, configuración de base de datos en la nube, etc.
