# GESTOR 002

## Arquitectura

Arquitectura propuesta para el desarrollo de aplicaciones con Spring Boot.

```bash
.
├── client
├── config
├── controller
├── mapping
├── model
├── payload
├── repository
├── services
└── tools
```

Esta arquitectura se basa en la separación de capas, cada una con una responsabilidad específica.
